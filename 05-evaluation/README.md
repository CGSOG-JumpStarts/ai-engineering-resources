# Evaluation resources

- [Model comparison procedure](model-selection.md): controlled experiments and actual-cost reporting.
- [Tool and security evaluation](agent-tool-evaluation.md): expected tool choices, denied actions, retries and truthfulness.
- [Scorecard](scorecard-template.md): editable form for a enterprise pilot.
- [Evaluation matrix](evaluation-matrix.csv): **example cases**. These are design examples, not results of an agent evaluation.
- [Offline evaluator](../06-reference-lab/README.md): executable, deterministic cases and JSON/Markdown report. This runs without Foundry/LLMs.

Never use a single aggregate grade to override a critical authorization or data disclosure failure. Test the outcome at the backend/tool boundary.
